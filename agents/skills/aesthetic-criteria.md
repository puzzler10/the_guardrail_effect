# Aesthetic Quality Criteria

Guidelines for creating visually distinctive, high-quality output that avoids generic "AI slop" aesthetics. Adapted from professional frontend design standards.

## Core Principles

### Color & Theme
- Commit to a cohesive aesthetic. Use CSS variables for consistency.
- **Dominant colors with sharp accents** outperform timid, evenly-distributed palettes.
- Dark mode should feel like OLED art — deep blacks, luminous highlights, not just "grey everything."
- Light mode should feel warm and intentional, not washed-out.

### Motion & Animation
- Focus on **high-impact moments**: one well-orchestrated catastrophic event effect creates more delight than scattered micro-animations.
- Use easing curves for everything — linear motion looks mechanical.
- Scroll-triggering and hover states that surprise.

### Spatial Composition
- Embrace asymmetry, overlap, and depth.
- Generous negative space OR controlled density — both work, but pick one.
- Grid-breaking elements create visual interest.

### Backgrounds & Visual Details
- Create atmosphere and depth — never default to flat solid colors.
- Apply contextual effects: gradient meshes, noise textures, geometric patterns, layered transparencies, dramatic shadows.
- Vignettes, grain overlays, and subtle patterns add perceived quality.

## What to NEVER Do

- **Generic purple gradients on white backgrounds** — the hallmark of AI-generated design
- **Default sans-serif fonts** (Inter, Roboto, Arial, system fonts) — choose something with character
- **Predictable symmetric layouts** — break the grid
- **Cookie-cutter component patterns** — every element should feel considered
- **Flat solid backgrounds** — add texture, gradient, or pattern
- **Random RGB colors** — derive everything from a cohesive palette
- **Linear fade-outs** — use exponential or cubic easing
- **Uniform particle sizes** — vary sizes for visual hierarchy

## What Makes People Stop and Look

1. **Contrast**: Something bright against something dark, or vice versa
2. **Movement patterns**: Particles flowing in ways that suggest natural forces
3. **Color temperature**: Warm accents (gold, coral) against cool backgrounds (deep blue, teal)
4. **Scale variation**: Tiny details alongside large elements
5. **Temporal rhythm**: Moments of calm punctuated by dramatic events
6. **Luminosity**: Things that appear to glow or emit light
7. **Layering**: Seeing through semi-transparent elements to layers behind

## Quick Self-Check

Before finishing visual work, ask:
- [ ] Would I screenshot this and share it?
- [ ] Does the color palette feel intentional, not random?
- [ ] Is there visual depth (not flat)?
- [ ] Do animations have easing (not linear)?
- [ ] Are there no harsh color transitions or popping?
- [ ] Does it look different from a typical tutorial project?
